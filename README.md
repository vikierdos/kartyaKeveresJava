# Kártyakeverés Java

Egyszerű Java program, ami egy kártyatrükköt valósít meg.

A program 21 kártyát rak ki 3 oszlopba. A felhasználónak háromszor meg kell adnia, hogy melyik oszlopban van a kiválasztott kártyája.

A program ezután megmondja, melyik kártyát választotta.

## Használt technológia

* Java
